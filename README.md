# สามก๊ก Atlas · 三國演義 Study

เว็บแอปอ่านสามก๊กครบ 120 ตอน (ค.ศ. 184–280) พร้อมเสียงอ่านภาษาไทย แผนที่เหตุการณ์ 5W1H ตัวละคร ไทม์ไลน์ และแบบทดสอบ

- ห้องอ่าน 4 เล่ม 120 ตอน + เสียงอ่าน (Web Speech API) ปรับความเร็วได้
- แผนที่ SVG 29 เหตุการณ์ พร้อมเส้นทางชีวิตตัวละคร
- ตัวละคร 17 คน พร้อมลักษณะนิสัย
- ค้นหา แบบทดสอบ และ PWA

Static site ไม่มี backend เปิดได้ทั้ง `file://`, XAMPP และ GitHub Pages

เนื้อหาเรียบเรียงใหม่เป็นภาษาไทยตามโครงเรื่องนิยายสามก๊กของหลอกวนจง ไม่ได้คัดลอกจากฉบับแปลใด
ชื่อที่ยังไม่ได้เทียบกับฉบับเจ้าพระยาพระคลัง (หน) ทำเครื่องหมายไว้ใน `data/glossary.js`
